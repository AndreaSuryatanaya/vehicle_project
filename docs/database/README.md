# Database diagram

## Schema diagram

The DBML source is [`schema.dbml`](./schema.dbml). To view or edit the diagram in dbdiagram.io:

1. Open [dbdiagram.io](https://dbdiagram.io).
2. Create a diagram and import or paste the contents of `schema.dbml`.
3. Export the diagram as an image or PDF if you need it in a project report.
